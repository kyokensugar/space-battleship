# Space Battleship Game — 要件定義書 v1.0

## 1. 目的
- 宇宙を舞台にした、古典ルールの Battleship ゲームを作る。
- プレイヤーは AI と1対1で対戦する。
- 副目的: 一般的なソフトウェア開発ライフサイクル(要件定義→設計→実装→テスト→デバッグ→デプロイ→振り返り)を体験・理解する。

## 2. 用語
| 用語 | 意味 |
|---|---|
| 宙域(グリッド) | 10×10 のマス目。自分用と敵用の2枚がある |
| 艦 | 縦または横に一直線に並ぶ 2〜5 マスの単位 |
| HP | 艦隊全体の「まだ撃たれていないマス数」の合計。初期値 17 |
| ヒット / ミス | 砲撃した座標に艦がある / ない |
| 撃沈 | 1つの艦の全マスがヒットした状態 |

## 3. ゲームルール(機能要件)

### 3.1 ゲーム開始
- R-01 難易度を Easy / Normal / Hard から選択できる。
- R-02 表示言語を 日本語 / English から選択できる(ゲーム中いつでも切替可)。
- R-03 プレイヤーは自分の艦5隻を宙域に配置する。
  - 艦の種類: 旗艦(5) / 戦艦(4) / 巡洋艦(3) / 駆逐艦(3) / 偵察艇(2) ※()はマス数
  - 縦・横のどちらかに配置。艦同士の重なりは不可。盤外は不可。
  - 「ランダム配置」ボタンで自動配置もできる。
- R-04 AI の艦配置はプレイヤーに見えない(ランダム配置)。
- R-05 先攻はプレイヤー。

### 3.2 ターン進行
- R-06 プレイヤーと AI が交互に行動する。1ターンに1回、相手宙域の座標を1つ指定して砲撃する。
- R-07 砲撃結果として ミス / ヒット / 撃沈(艦名つき) を表示する。
- R-08 同じ座標を2度撃つことはできない(UIで選べないようにする)。
- R-09 両者の残り HP と現在ターン数を常に表示する。
- R-10 最大ターン数は 各プレイヤー 50 ターン(合計100手)。

### 3.3 勝敗
- R-11 相手の全艦を撃沈(相手 HP = 0)した側の勝ち。
- R-12 最大ターン数に達した場合、残り HP が少ない側が敗北。同数なら引き分け。
- R-13 決着後、結果画面(勝敗・ターン数・両者の残りHP・敵の配置公開)を表示し、「もう一度遊ぶ」で開始画面に戻れる。

### 3.4 AI の難易度
- R-14 Easy: 未砲撃マスから完全ランダムに選ぶ。
- R-15 Normal: ヒットしたら隣接マスを優先して狙う(「追撃」モード)。撃沈後はランダムに戻る。
- R-16 Hard: Normal に加え、「艦が置ける可能性のある場所」を数えた確率マップで最も確率の高いマスを狙う。

## 4. 非機能要件
- N-01 多言語: UI 文言はすべて辞書ファイルに分離し、言語追加がコード変更なしに近い形でできる。
- N-02 レスポンス: プレイヤー操作から画面反映まで体感的に即時(0.1秒以内)。AI の手番は演出として 0.5〜1 秒の間をおく。
- N-03 動作環境: 最新の Chrome / Safari / Edge で動作(ブラウザ版の場合)。
- N-04 テスト: ゲームロジック(配置判定・ヒット判定・勝敗判定・AI)は自動テストで検証する。
- N-05 状態保存はしない(ページを閉じたらゲーム終了)。将来の拡張候補。

## 5. スコープ外(今回は作らない)
- 対人対戦(オンライン/ローカル)
- サイコロ、イベントマス、MP、艦の移動などの独自要素
- ランキング、セーブ、アカウント機能
- 効果音・BGM(余裕があれば「振り返り」後の拡張候補)

## 6. 完成の定義(これができたら「完成」)
1. 難易度と言語を選んでゲームを開始できる。
2. 艦を配置し、AI と交互に砲撃して勝敗が決まる。
3. 3つの難易度で AI の挙動が明確に異なる。
4. 日本語 / 英語の切替で全文言が切り替わる。
5. 自動テストがすべて成功する。
6. URL を開けば誰でも遊べる状態で公開されている(デプロイ)。
